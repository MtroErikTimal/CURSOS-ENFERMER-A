# Imágenes — Fundamentos de Enfermería I

Sube aquí imágenes didácticas de esta asignatura.

- Formatos sugeridos: `.jpg`, `.jpeg`, `.png`, `.webp` o `.svg`.
- Usa nombres descriptivos, sin espacios ni acentos. Ejemplo: `partes-expediente-clinico.png`.
- Evita incluir datos personales o identificables de pacientes.
